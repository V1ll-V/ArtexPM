# 授权渗透任务模板

[authorized-pentest.json](authorized-pentest.json) 保存四份模板正文：侦察与攻击面梳理、漏洞发现与证据采集、定向复现与修复复测、全流程测试与报告交付。`legacy_name` 仅用于识别原比赛模板，不进入新任务描述。

当前本机实例已原位更新原模板，保留编号、分类及拦截/允许规则。更新前后快照在用户目录 `artex-backups/task-templates-authorized-20261102/`；已有任务的描述和目标未回填修改。刷新新建任务页面后，选择对应授权模板并填写所有占位项。

其他实例可在「任务模板」管理界面按文件中的 name/description/goal 创建或更新；这个 JSON 是受版本控制的参考数据，不会在程序启动时自动导入或覆盖用户模板。

授权边界、账号权限、测试时间窗、允许动作、禁测项及预算由委托项目明确。把资产清单同步到任务范围和实际拦截/允许规则，不能仅靠描述文字形成执行层限制。密码与密钥使用安全凭据引用，不保存到模板。

任务完成围绕约定覆盖与结果交付，不强求发现漏洞；候选、有效确认、否定及受限项分别交付。正式漏洞结论仍需独立验收，不用材料报告代替成功 PoC。复测先关联原任务，复用原 finding 和证据；关键条件无法取得时记录缺口并有界收尾。
